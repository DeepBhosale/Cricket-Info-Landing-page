# Boundary

A dependency-free landing page for exploring international cricket teams, ODI player stats, recent form and upcoming fixtures.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package installation is required.

## Benchmark notes

This demo is intentionally broken for code-intelligence and repair testing: the page is hidden by a stylesheet regression, and its JavaScript initialization calls a nonexistent function. The page should not render until those code defects are repaired. No informational data has been changed to create the breakage, and no exploitable security vulnerabilities are included. The displayed statistics are illustrative and are not an authoritative live data source. No authentication, personal data, or network-backed application API is included.
